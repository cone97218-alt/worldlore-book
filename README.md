# A助手 (Worldlore Agent) 🌌

> **SillyTavern (酒馆) 沉浸式世界书与角色卡设定 Agent 扩展**

A助手 是一个专为 SillyTavern 设计的现代化世界书构建、角色卡创作与设定管理工作流扩展。它兼具**独立草稿工作区**、**待同步暂存审核区**、**原子级快照日志与撤回/重做引擎**，并深度打通酒馆底层世界书与角色数据模型。

---

## ✨ 核心特性

### 1. 📂 独立草稿工作区 (Workspace & Projects)
- **一体化折叠面板**：顶部仅保留极简信息条，编辑器直达近 100% 抽屉可视高度；
- **多项目与文件管理**：支持多套写卡工程（新建、导出、导入、删除）、全文搜索与大容量文件列表浏览；
- **草稿随时调用**：AI 可在草稿中任意推演大纲，完全隔离，不污染正式世界书。

### 2. 🎛️ 待同步暂存区 (Staging Area)
- **AI 变更可视化审核**：AI 生成或修改的世界书条目、角色卡字段全部先推送到暂存区，由您一键勾选应用或丢弃；
- **蓝绿灯与顺序实时交互**：
  - 🔵 **蓝灯**：常驻生效模式（无需触发词）；
  - 🟢 **绿灯**：关键词触发模式；
  - 🟢 **开启** / 🔴 **关闭**：条目启用与禁用状态；
  - 🔢 **顺序**：内联数字调节排序优先级（数字越大插入越靠前）；
  - 📐 **位置与深度**：支持下拉选择前置角色、后置角色、前置AN、深度插入（可设定插入深度）。

### 3. ⏪ 操作日志与撤回/重做闭环 (History & Undo / Redo / Re-Stage)
- **全状态快照记录**：记录每一次对世界书、角色卡、Persona 与草稿的变更；
- **一键原子级撤回 (Undo)**：瞬间回滚所有字段与条目数据；
- **一键重做 (Redo)**：手滑撤回后一键恢复生效；
- **重新暂存 (Re-Stage)**：撤回后可一键将设定重新打包推回暂存区二次审核。

### 4. 🌐 多范围世界书穿透读取 (Multi-Scope Lorebook Access)
- 默认精准读取当前角色绑定世界书，防止混淆跨作品设定；
- 支持 character、chat、global、ctive、ll 作用域切换；
- 支持传入具体 ook_name 精准穿透读取任意世界书条目。

### 5. 🎨 极致轻量与优雅 UI
- **纯 FontAwesome 图标设计**：清爽无冗余文字干扰；
- **3 套精美主题**：跟随酒馆原生 / 莫兰迪米色 / 莫兰迪灰色（100% 不透明度防重叠）；
- **GPU 60fps 平滑贴边悬浮球**：拖动吸附贴边，轻触即开；
- **魔法棒菜单总控**：在酒馆拓展菜单中点击 A助手 即可随时开启或隐藏悬浮球。

2. 在 **从 URL 安装扩展** 输入框中粘贴仓库地址：

## 🛠️ 工具指令 (Tool Calling) 说明

本插件支持原生 **Function Calling** 以及普通文本模型（如 DeepSeek、Claude、GPT 文本模式等）的 `<agent_action>` 标签解析。

支持的核心工具包括：
- **`st_create_and_bind_lorebook`**：新建世界书并自动绑定到当前角色卡（支持草稿与条目一站式注入）；
- **`st_delete_lorebook`**：彻底删除世界书并自动解绑（支持操作日志一键无损撤回恢复）；
- **`stage_lorebook_entry`**：暂存世界书条目变更（支持 `from_file` 零 Token 直通）；
- **`stage_character_field`** / **`stage_persona_field`**：暂存角色与用户设定变更；
- **`workspace_write`** / **`workspace_patch`** / **`workspace_delete`** / **`workspace_read`** / **`workspace_rename`** / **`workspace_rename_project`**：工作区草稿写入、差量精准替换、安全删除、读取与重命名；
- **`st_read_lorebook`** / **`st_get_lorebooks_overview`**：多范围穿透读取世界书。

在系统提示词 (System Prompt) 中可直接引入工具说明，点击插件抽屉第四栏【提示词指南】即可一键复制完整 Prompt！
